# Phantom Ads

Production website for https://phantomads.online, hosted by the Cloudflare Pages project phantomads-online in the Mayfairpug account.

## Deployment

Cloudflare deploys the main branch of this repository. Keep the project root and build command empty, and use the repository root as the output directory. The website requires no build or dependencies.

index.html contains the complete site, including styles, scripts and four embedded ad screenshots. 404.html, _headers and robots.txt provide the error page, response headers and crawler settings.

The older assets, styles.css and script.js are retained for reference but are not loaded by index.html.
